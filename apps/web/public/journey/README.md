# Journey step pictures

Drop one picture per step here and the home page's "From sketch to you" cards use it
straight away (until a file exists, the card shows a crop of a real design photo or a gold
line drawing). Use your own workshop photos, or a library licensed for commercial use
(Unsplash, Pexels). Portrait or square, at least 900 px wide, JPG or WebP.

| File | Show |
| --- | --- |

| `03-pattern.jpg` | A paper pattern being drafted with a ruler and chalk |
| `04-cutting.jpg` | Scissors cutting the fabric on the table |
| `05-stitching.jpg` | A tailor at the sewing machine, or hand stitching a seam |
| `06-quality.jpg` | Measuring tape on a finished seam, a close inspection |

`.webp` works too: name it `01-sketch.webp` and so on. The first file found per step wins.
